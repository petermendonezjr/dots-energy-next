Adding the Interactive Map to Your Squarespace Site

This guide walks you through embedding the Dots Energy operations map into your Squarespace page. You don't need to publish your Squarespace site yet — the map will show up in your editor preview. No coding experience needed.

// What is the interactive map?

The map is a self-contained web page that shows all Dots Energy operational sites across the US. Visitors can hover over markers to see site names and click them to see details like capacity, type, and status. It has a color-coded legend (offices, battery storage, microgrids) and works on both desktop and mobile. You can preview it yourself by visiting the URL below.

// The map is already hosted here

The map is hosted on our GitHub Pages site. This is the live URL — open it in your browser to see what visitors will see:

https://petermendonezjr.github.io/dots-energy-next/embed/map.html
// How this works

Squarespace doesn't let you upload HTML files directly, so we host the map separately and display it on your page using an iframe — a small snippet that tells Squarespace "load this web page inside my page." The map stays in sync automatically: when the Dots Energy team updates the map, the changes appear on your Squarespace site without you needing to do anything.

// Step-by-step: Add the map to your page
1
Open your Squarespace page editor
Log into Squarespace and navigate to the page where you want the map to appear. Click Edit (top-left corner) to enter the page editor. Click the + icon to add a new content block in the section where the map should go.
2
Add a Code block
In the block picker, scroll down to the More section and select Code. This opens a text box where you can paste HTML. At the bottom of the editor, make sure "Display Source" is turned OFF — this tells Squarespace to render the code as a live interactive element, not display it as raw text.
3
Paste this embed code
Copy the code below and paste it into the Code block. This is the only code you need — it tells Squarespace to load the map from our server:
<!-- Dots Energy Interactive Map --> <div style="width:100%; max-width:1200px; margin:0 auto;"> <iframe src="https://petermendonezjr.github.io/dots-energy-next/embed/map.html" width="100%" height="700" frameborder="0" style="border:none; border-radius:8px;" loading="lazy" title="Dots Energy Operations Map"> </iframe> </div>
4
Save and preview
Click Save on the Code block, then Save on the page. Use Squarespace's built-in preview to confirm the map loads — you don't need to publish. Try clicking a site marker to test the popup detail cards. Check the mobile preview too — the map is fully responsive.
// You're done

The map should now appear in your Squarespace editor preview. When you're ready to go live, just publish your Squarespace site as normal — the map embed will work automatically. When the Dots Energy team adds or updates sites, the changes will appear on your page without any action from you.

// Optional adjustments
Map is too tall or short?
Change height="700" in the embed code. Try 500 for a more compact view, or 800 for a more immersive feel. The width fills automatically.
Want more spacing?
In Squarespace, click the section containing the Code block and adjust the top/bottom padding in section settings. 40–60px per side works well.
Map not loading?
Make sure "Display Source" is OFF on the Code block. If the map still doesn't appear, try opening the URL above directly in your browser to confirm it's accessible.
Need site data changed?
Contact the Dots Energy dev team. They'll update the map file on the server — the changes will appear on your Squarespace page automatically, no action needed from you.
// Changing the map colors

If you want to adjust the map's colors to match your site's palette, open map.html in any text editor (TextEdit on Mac, Notepad on Windows). Near the top of the file (around line 12), you'll find a section that looks like this:

--color-office: #3B82F6; /* blue — office markers */ --color-battery: #F59E0B; /* amber — battery storage markers */ --color-microgrid: #10B981; /* green — microgrid markers */ --accent: #C2713A; /* warm brown — hover states, legend highlight */ --map-land: #D5D9DE; /* light gray — US state fill color */ --map-border: #B0B8C4; /* medium gray — state border lines */

To change a color: replace the hex code (e.g., #3B82F6) with any color you want. You can use a free color picker like htmlcolorcodes.com to find hex values. Save the file, then ask the Dots Energy dev team to re-upload it — the update will go live automatically.

// Keep it simple

Only change the hex values (the #XXXXXX codes). Don't delete the semicolons, dashes, or variable names. If something looks broken after editing, just undo your changes or ask the dev team for help.
